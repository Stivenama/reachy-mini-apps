# Audio Mixer

Aplicación para seleccionar la salida de sonido del Reachy Mini y controlar el mezclador. Necesita el daemon de Reachy y los servicios de audio del sistema operativo del robot.

Se registra mediante el punto de entrada `reachy_mini_audio_mixer`. Las selecciones de dispositivos de cada equipo se configuran localmente; no se publican grabaciones ni preferencias privadas.
