# Reachy Mini Hub

Código del Hub y sus adaptaciones locales, recuperado de la carpeta de desarrollo del robot. Incluye conversación, movimientos, gestión de herramientas y una integración opcional con un puente MG400.

La configuración privada y los perfiles personales se sustituyeron por `.env.example` y un perfil genérico en español. Definir `MG400_BRIDGE_URL` localmente para utilizar el brazo; no se incluye ninguna dirección de la instalación original.

Consultar la guía de instalación en la raíz del repositorio y `THIRD_PARTY.md`. El código conserva los metadatos de autoría de Pollen Robotics.
